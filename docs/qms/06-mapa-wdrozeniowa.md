## Normy techniczne poza systemem zarządzania

- ISO/IEC 25010:2023 — model jakości produktów ICT, wykorzystywany do formułowania kryteriów testów; https://www.iso.org/standard/78176.html.
- ISO 15930, ISO 12647 i normy pokrewne — stosować selektywnie do DTP/prepress zgodnie z technologią i wymogami drukarni.
- Automatyczne testy dostępności oraz GitHub Actions **nie stanowią certyfikacji ISO**.

## Następna decyzja

Po pilotażu co najmniej kilku realizacji: przegląd faktycznych dowodów, dostosowanie polityki, analiza luk względem pełnego wydania ISO 9001:2026, audyt wewnętrzny, rozważenie certyfikacji zewnętrznej wyłącznie przy biznesowej potrzebie.
