# v1.0.3: diagnostyka konfiguracji wysyłki

GET /api/inquiries zwraca wyłącznie informację o obecności konfiguracji bazy, dostawcy powiadomień oraz flagi aktywacji. Nie ujawnia wartości, adresów, sekretów ani rekordów klientów. Odpowiedź jest niebuforowana i wykluczona z indeksowania. POST i dotychczasowe formularze pozostają bez zmian.

Pozwala sprawdzić gotowość serwera podczas niedostępności panelu Cloudflare. Sama obecność konfiguracji nie potwierdza poprawności klucza ani dostarczenia poczty.
